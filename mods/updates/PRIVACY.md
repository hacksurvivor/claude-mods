# Updates privacy policy

Last updated: October 4, 2026

Updates is a Claude Code mod by hacksurvivor. It runs on your own computer. It has no server, no account and no analytics, and its author receives nothing from it.

## What it reads

Your installed Claude Code plugins and marketplaces (`~/.claude/plugins`), which plugins are on (`~/.claude/settings.json`), your global npm packages, Codex's plugin cache, `~/.claude/updates/sources.json`, and the files that config names.

## What it sends, and where

- To **GitHub**, through the GitHub CLI you signed in to: read-only requests for plugin manifests, releases and commit comparisons of public repositories.
- To the **npm registry**, through npm: the names of your global packages, to look up their latest versions.
- To **Anthropic**, through Claude Code under your Claude account: the release notes of what it found, for one-line summaries. See https://www.anthropic.com/legal/privacy.

## What it keeps

The latest report, in Claude Code's plugin store on your computer.

## Children

Updates is not intended for people under 18.
