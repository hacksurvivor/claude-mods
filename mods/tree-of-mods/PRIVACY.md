# The Tree of Mods privacy policy

Last updated: October 4, 2026

The Tree of Mods is a Claude Code mod by hacksurvivor. It runs on your own computer. It has no server, no account and no analytics, and its author receives nothing from it.

## What it reads

Your mods folder and its git state, your installed Claude Code plugins and settings, the Updates mod's report, each mod's own plugin store (for counts like "3 links judged"), and `~/.claude/tree-of-mods/config.json`.

## What it sends, and where

- To **GitHub**, through the GitHub CLI you signed in to: read-only requests for your repository's traffic (clones, views, popular pages) and stars.
- When you press **Update**: whatever that update's command contacts (for example npm or a plugin marketplace).
- When you press **Publish**: a prompt to Claude, sent to **Anthropic under your Claude account** like any message.

## What it keeps

In `~/.claude/tree-of-mods/` on your computer: test results, GitHub numbers (refreshed hourly), the latest update recheck, and a backup of your settings from before the last switch.

## Children

The Tree of Mods is not intended for people under 18.

## Contact

Open an issue at https://github.com/hacksurvivor/claude-mods/issues.
